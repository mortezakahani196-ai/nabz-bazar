# نبض بازار — MVP اولیه

یک اسکلت قابل اجرا برای دستیار هوشمند بازار سرمایه ایران:
- داشبورد فارسی و راست‌چین
- API با FastAPI
- داده‌های نمایشیِ مشخص‌شده به‌عنوان نمونه
- نقطه شروع برای اتصال منابع خبری و داده‌های واقعی بازار

## پیش‌نیازها
- Python 3.10 یا جدیدتر

## اجرا
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload
```
سپس در مرورگر باز کن:
- داشبورد: http://127.0.0.1:8000
- مستندات API: http://127.0.0.1:8000/docs

## وضعیت فعلی
این نسخه فقط اسکلت رابط و API است. هیچ داده زنده، اتصال به کدال، قیمت لحظه‌ای، مدل AI یا سیگنال واقعی به آن وصل نشده است. داده‌های نمونه نباید مبنای معامله قرار بگیرند.

## گام‌های بعدی
1. انتخاب منبع داده قیمت و حجم بازار با مجوز و پایداری مناسب.
2. افزودن جمع‌آوری خبر از منابع مجاز و ذخیره URL، زمان انتشار و نام منبع.
3. افزودن تحلیل خبر با خروجی ساخت‌یافته و پیوند به متن اصلی.
4. افزودن موتور قواعد، مدیریت ریسک و ثبت معاملات فرضی.
5. تست تاریخی و پایش کیفیت هشدارها پیش از استفاده واقعی.
